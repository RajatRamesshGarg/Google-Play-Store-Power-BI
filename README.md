# Google-Play-Store-Power-BI
## Project Overview

This project analyzes the Google Play Store dataset using Power BI. The main objective is to understand app performance, user preferences, and market trends through interactive dashboards.

The dashboard helps answer business questions such as:
- Which app categories are the most popular?
- What factors influence app ratings?
- How do installs, reviews, and prices affect app performance?
- Which genres have the highest user engagement?
- 
- ## Project Objectives

- Analyze Google Play Store applications.
- Understand app ratings and installs.
- Compare free and paid apps.
- Identify top-performing categories and genres.
- Create an interactive dashboard for business decision-making.

## Data Cleaning

The following data cleaning steps were performed using Power Query:

- Removed duplicate records
- Fixed incorrect data types
- Converted Ratings into numeric values
- Cleaned Reviews and Installs columns
- Converted Last Updated into Date format
- Removed missing and invalid values
- Standardized text values
- Prepared the dataset for dashboard creation

- ## Key Insights

- Most apps available on the Play Store are **Free**.
- A small number of categories contribute to the majority of app installs.
- Apps with higher installs generally receive better ratings.
- High app prices do not guarantee better ratings.
- Genres with more than one million installs represent strong market opportunities.
- Apps that are updated regularly usually perform better and provide a better user experience.
- Games and Communication are among the most popular categories.
- User reviews are a good indicator of app popularity.

- ## Recommendations

- Focus on developing free apps with optional premium features.
- Keep apps updated regularly to improve user satisfaction.
- Encourage users to leave ratings and reviews.
- Prioritize high-demand categories and genres.
- Optimize app size to improve downloads.
- Improve app quality before increasing pricing.
- Monitor user feedback continuously for improvements.

- ## Challenges Faced

During this project, several challenges were encountered:

- Incorrect data types in multiple columns.
- Errors while converting the **Installs** column into numeric values.
- Missing and invalid values such as "NaN".
- Cleaning symbols like "+", "," and "$" from data.
- Handling inconsistent data formats.
- Creating DAX measures for KPIs.
- Selecting appropriate visuals for business insights.

These challenges were resolved using Power Query transformations and DAX calculations.

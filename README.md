# 📱 Google Play Store Power BI Dashboard

## 📌 Project Overview

This project analyzes the **Google Play Store dataset** using **Microsoft Power BI** to uncover valuable insights into app performance, user preferences, and market trends through an interactive dashboard.

The dashboard helps answer important business questions such as:

- Which app categories are the most popular?
- What factors influence app ratings?
- How do installs, reviews, and prices affect app performance?
- Which genres have the highest user engagement?

---

# 🎯 Project Objectives

- Analyze Google Play Store applications.
- Understand app ratings and installation trends.
- Compare the performance of Free and Paid apps.
- Identify top-performing categories and genres.
- Build an interactive dashboard for business decision-making.

---

# 🧹 Data Cleaning

The dataset was cleaned and transformed using **Power Query**.

### Cleaning Steps Performed

- Removed duplicate records.
- Corrected incorrect data types.
- Converted Ratings into numeric values.
- Cleaned Reviews and Installs columns.
- Removed symbols such as "+", "," and "$".
- Converted **Last Updated** into Date format.
- Removed missing and invalid values (NaN).
- Standardized inconsistent text values.
- Prepared the dataset for dashboard development.

---

# 📈 Key Insights

- Most applications available on the Play Store are **Free**.
- A small number of categories contribute to the majority of app installs.
- Apps with higher installs generally receive better ratings.
- Higher app prices do not necessarily result in better ratings.
- Genres with over one million installs represent strong market opportunities.
- Regularly updated apps generally perform better and provide a better user experience.
- **Games** and **Communication** are among the most popular categories.
- User reviews are a strong indicator of app popularity.

---

# 💡 Recommendations

- Focus on developing free apps with optional premium features.
- Keep applications updated regularly to improve user satisfaction.
- Encourage users to leave ratings and reviews.
- Prioritize high-demand categories and genres.
- Optimize app size to improve downloads.
- Improve app quality before increasing pricing.
- Continuously monitor user feedback for future improvements.

---

# ⚠️ Challenges Faced

During this project, the following challenges were encountered:

- Incorrect data types across multiple columns.
- Errors while converting the **Installs** column into numeric values.
- Missing and invalid values such as **NaN**.
- Cleaning symbols like **"+", "," and "$"** from numerical fields.
- Handling inconsistent data formats.
- Creating DAX measures for KPIs.
- Selecting appropriate visualizations for business insights.

These challenges were resolved using **Power Query transformations** and **DAX calculations**.
